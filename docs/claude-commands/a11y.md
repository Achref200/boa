---
description: Run the accessibility gate and fix what it finds
---

```bash
npx playwright test tests/e2e/accessibility.spec.ts
```

For each violation:

1. Name the rule, the page and the element.
2. Fix the **interface**. Do not lower the threshold, do not narrow the scan,
   do not add an exclusion.
3. For a `color-contrast` failure: the fix is a token in `src/styles/tokens.css`
   with the measured ratio in a comment beside it — never `opacity-*` on text,
   and never a raw hex in a component. Remember the two grounds: a value must
   clear 4.5:1 on the surface it is actually used on
   (`#FFFFFF`, `#F4F4F2`, `#E8E8E5` for paper; `#27282A`, `#303134` for ink).
4. Re-run until green, then confirm nothing else regressed:
   `npm run e2e`.

The gate is WCAG 2.1 AA. It also covers keyboard-only add-to-cart and the mobile
menu focus trap — a fix that breaks those has not fixed anything.
